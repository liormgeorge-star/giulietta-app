מהטלפון למחשב

הגדרת שליטה מרחוק

דרך RustDesk: קוד פתוח, מוצפן מקצה לקצה, עובד בבית וגם מחוץ לבית בלי להגדיר את הראוטר.

  1. RustDesk במחשב
  2. סיסמה לשליטה מרחוק
  3. RustDesk בטלפון
  4. חיבור ראשון
    ב-RustDesk בטלפון מזינים את מזהה המחשב, ואחר כך את הסיסמה, ומסמנים "זכור סיסמה". מהפעם הבאה הכפתור "שליטה מרחוק" פותח את זה ישר.
    —

הגדרת משחקים

דרך Steam Link של Valve: סטרימינג של משחקים מהמחשב, גם עם שלט, בבית וגם מחוץ לבית.

  1. Steam במחשב
  2. Steam Link בטלפון
    חינמי ב-Google Play.
  3. צימוד, פעם אחת
    פותחים את Steam Link בטלפון ובוחרים במחשב. הוא יציג קוד בן 4 ספרות. מקלידים אותו בחלון שנפתח ב-Steam במחשב.

גישה מחוץ לבית

דרך Tailscale: רשת פרטית ומוצפנת בין הטלפון למחשב. לא פותחים שום פורט בראוטר, והמחשב לא נחשף לאינטרנט. חינמי לשימוש אישי. את השלבים עושים פעם אחת, בבית.

  1. פותחים חשבון Tailscale
    אפשר עם חשבון Google. זה החשבון שיחבר בין הטלפון למחשב.
  2. Tailscale בטלפון
    מתקינים ונכנסים עם אותו חשבון.
  3. חיבור המחשב
    בעמוד שנפתח: Generate auth key, בלי Reusable ובלי Ephemeral. מעתיקים את המפתח (מתחיל ב-tskey-).
  4. שליטה ומשחקים מחוץ לבית
    RustDesk ו-Steam Link עובדים מחוץ לבית גם בלי Tailscale, דרך שרת מוצפן. Tailscale מוסיף את כפתורי החשמל (כיבוי, שינה, הפעלה מחדש) מחוץ לבית, וחיבור ישיר ומהיר יותר. כתובת המחשב ב-Tailscale:
    —
  5. שהמחשב לא יתנתק אחרי חצי שנה
    ברשימת המכשירים של Tailscale: ליד שם המחשב ← ⋯ ← Disable key expiry.

הדלקה מחוץ לבית צריכה מכשיר שנשאר דלוק בבית (למשל Raspberry Pi). כשיוצאים מהבית עדיף להכניס את המחשב ל"שינה" ולא לכבות אותו. פרטים בדו"ח המחקר.

עדכון אחרון ידני במחשב

התוכנה במחשב היא מהגרסה הראשונה, שלא יודעת להתעדכן לבד. מתקינים אותה מחדש פעם אחת. קוד הצימוד נשאר.
