גישה מחוץ לבית

דרך Tailscale: רשת פרטית ומוצפנת בין הטלפון למחשב. לא פותחים שום פורט בראוטר, והמחשב לא נחשף לאינטרנט. חינמי לשימוש אישי. את השלבים עושים פעם אחת, בבית.

  1. פותחים חשבון Tailscale
    אפשר עם חשבון Google. זה החשבון שיחבר בין הטלפון למחשב.
  2. Tailscale בטלפון
    מתקינים ונכנסים עם אותו חשבון.
  3. חיבור המחשב
    בעמוד שנפתח: Generate auth key, בלי Reusable ובלי Ephemeral. מעתיקים את המפתח (מתחיל ב-tskey-).
  4. Moonlight מחוץ לבית
    ב-Moonlight: לוחצים על "+" ומזינים את הכתובת הזו. היא מתחברת לאותו מחשב, בלי צימוד נוסף.
    —
  5. שהמחשב לא יתנתק אחרי חצי שנה
    ברשימת המכשירים של Tailscale: ליד שם המחשב ← ⋯ ← Disable key expiry.

הדלקה מחוץ לבית צריכה מכשיר שנשאר דלוק בבית (למשל Raspberry Pi). כשיוצאים מהבית עדיף להכניס את המחשב ל"שינה" ולא לכבות אותו. פרטים בדו"ח המחקר.

עדכון אחרון ידני במחשב

התוכנה במחשב היא מהגרסה הראשונה, שלא יודעת להתעדכן לבד. מתקינים אותה מחדש פעם אחת. קוד הצימוד נשאר.
