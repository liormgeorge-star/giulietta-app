# שלט מחשב

אפליקציה לאנדרואיד מול מחשב Windows:
- **חשמל:** הדלקה, כיבוי, הפעלה מחדש ושינה.
- **שליטה מרחוק:** שולחן העבודה בטלפון.
- **משחקים:** סטרימינג, גם עם שלט.
- **גישה מחוץ לבית:** דרך Tailscale, רשת פרטית ומוצפנת, בלי לפתוח פורטים.
- **30 עיצובים לבחירה:** הגדרות ← עיצוב.

## הורדה
מדף ה-**Releases**, גרסת **PC Remote (latest)**:
- `pc-remote.apk`: לטלפון. גרסה חדשה מותקנת מעל הקודמת, והפרטים נשמרים.
- `pc-remote-windows.zip`: למחשב. מספיק להתקין פעם אחת, ומשם התוכנה מתעדכנת דרך האפליקציה.

## התקנה ראשונה (בבית)
1. **במחשב:** מחלצים את הקובץ (כפתור ימני ← חלץ הכל), וב-**install.cmd** לוחצים כפתור ימני ← הפעל כמנהל. ההתקנה מתקינה גם את Sunshine מול העיניים ושואלת שם משתמש וסיסמה בשבילו. בסוף יוצגו כתובת IP וקוד צימוד.
2. **בטלפון:** מזינים את הכתובת ואת הקוד.
3. **סטרימינג:** לוחצים על "שליטה מרחוק" ועוקבים אחרי השלבים (Moonlight וצימוד בקוד בן 4 ספרות).
4. **מחוץ לבית:** הגדרות ← "גישה מחוץ לבית" ועוקבים אחרי השלבים:
   - פותחים חשבון Tailscale;
   - מתקינים Tailscale בטלפון;
   - יוצרים מפתח הצטרפות ומדביקים אותו באפליקציה. המחשב מתקין ומתחבר לבד;
   - מוסיפים ב-Moonlight את כתובת ה-100.x שהאפליקציה מציגה.

### פעם אחת, ידנית
- **BIOS:** מפעילים Wake on LAN ומכבים ErP.
- **ראוטר:** שומרים למחשב כתובת IP קבועה (DHCP Reservation).
- **Tailscale:** ברשימת המכשירים, ליד המחשב: Disable key expiry.

## מחוץ לבית – מה עובד
| פעולה | בבית | מחוץ לבית (Tailscale) |
|---|---|---|
| מצב המחשב, כיבוי, הפעלה מחדש, שינה | כן | כן |
| שליטה מרחוק ומשחקים | כן | כן |
| הדלקה | כן (Wake-on-LAN) | רק עם מכשיר שנשאר דלוק בבית* |

\* אות ההדלקה הוא שידור שלא עובר דרך האינטרנט או דרך Tailscale, ולכן צריך מכשיר בבית שישלח אותו. האפשרויות ממוינות בדו"ח המחקר: Raspberry Pi עם UpSnap, ראוטר עם תמיכה, או שקע חכם עם הגדרת BIOS. עד אז, כשיוצאים מהבית עדיף להכניס את המחשב ל"שינה".

אם Moonlight לא מתחבר מחוץ לבית: בבית עם סיב של בזק (CGNAT) שגם הטלפון בחבילת גלישה, Tailscale לפעמים לא מצליח ליצור חיבור ישיר. הפתרונות: כתובת IP ציבורית מהספק או IPv6.

## אבטחה
פירוט מלא ב-[SECURITY.md](SECURITY.md). בקצרה:
- **הקוד מוגן:** קוד הצימוד לא עובר ברשת. כל פקודה חתומה ומוצפנת ומוגנת מפני שידור חוזר, ותשובות המחשב חתומות.
- **אין חשיפה לאינטרנט:** שום דבר לא פתוח לאינטרנט, וחומת האש מאפשרת רק את רשת הבית ואת Tailscale.
- **Sunshine:** מתעדכן לגרסה שכוללת את תיקוני האבטחה של 2026, והגדרותיו מוקשחות.
- **עדכונים:** עדכון של תוכנת המחשב מותקן רק אם הוא תואם בדיוק לחבילה שהאפליקציה נבנתה איתה.

## אם משהו לא עובד
- **יומן במחשב:** `C:\ProgramData\PcRemote\agent.log`.
- **"יותר מדי ניסיונות שגויים":** המחשב חוסם את הטלפון ל-15 דקות.
- **רואים את הקוד מחדש:** מריצים שוב `install.cmd`. הקוד לא נשמר בקובץ גלוי.

## לפיתוח
העיצובים נוצרים מטבלה אחת:
1. עורכים את `tools/gen_themes.py` (צבעים וגופנים) ואת `tools/themes-extra.css` (פרטים לכל עיצוב).
2. מריצים `python3 tools/gen_themes.py`.

## הסרה
- **מחשב:** `uninstall.cmd`. את Sunshine ואת Tailscale מסירים מ"הגדרות ← אפליקציות".
- **טלפון:** כרגיל.
